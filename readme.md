# WhatsApp Theme Manager- Whave

A browser extension for managing WhatsApp web theme.

- [Extension on Google Chrome Store](https://chrome.google.com/webstore/detail/whave/onmmaefeecidiliagmmbelkaeicmaang?utm_source=chrome-ntp-icon)

**Why**
Most applications offer 3 primary theme modes: Dark, Light and System, System allows automatic updates by OS time but what if you run fixed Dark or Light on OS yet want automatic theme changes on Whatsapp by time.

- This extension does just that for WhatsApp Web

**Features**

1. Automatically switch theme between day and night time
2. Switch between themes manually via a easily accessed menu

**Planned**

- Support custom start and end time for theme switches `ongoing`
- Support multiple times
- Support custom and predefined themes
- Support Firefox
